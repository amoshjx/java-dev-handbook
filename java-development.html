开发实现

项目排期（第 04 章，独立一级）之后、测试与质量（第 18 章）之前的主线：环境 → 语言与运行时 → Spring → 构建部署 → RuoYi → 业务模块 → 安全 → TDD。本模块涵盖 05–17 章，便于跨章引用与 prev/next 线性阅读（03 → 04 → 05 → … → 17 → 18）。采用 Java 语言进行开发实现，默认基线与全书一致：Java 21 LTS、Spring Framework 6.x / Spring Boot 3.x（Jakarta EE 9+）。

05 开发环境搭建 — Windows/WSL 一站式安装

覆盖 Java/Git/Maven/WSL、WSL 内 Docker/minikube、IDE、数据库与远程工具的安装、验证与排障。

06 Java基础语法

语法、类型系统与现代 Java 编码习惯，并整合集合/泛型/Stream 进阶基础。

07 面向对象

建模、封装、SOLID 与不可变对象。

08 JVM

以 Java 21 为基线，系统讲解 JVM 定位、运行时数据区、类加载、JIT、GC、诊断与线上排障。

09 并发编程

线程、锁、线程池与异步编排。

10 IO·NIO·网络

文件 IO、NIO 与 HTTP 客户端。

11 持久化

SQL 优化、索引、事务与连接池。

12 Spring Framework

Spring Framework 6 应用开发：IoC/DI、AOP、MVC、数据访问、事务、配置、事件、校验与分层实践。

13 项目构建、打包与部署

Maven 构建、Docker 镜像、Kubernetes 部署与 CI/CD 完整实操链路。

14 RuoYi 框架

企业后台脚手架简明介绍：管理后台、权限系统、代码生成、官方文档与生产注意点。

15 常见功能模块

RBAC、支付、校验、定时任务、消息、工作流等企业标配。

16 安全开发

Spring Security、OWASP 防护、密钥/TLS 与审计合规。

17 测试驱动开发

TDD 红绿重构、测试金字塔、Fake/Mock 选型与团队 CI 实践。
